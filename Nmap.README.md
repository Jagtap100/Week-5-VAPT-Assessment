# Nmap – Network Scanning

## Objective

The objective of this practical is to use Nmap (Network Mapper) to identify open ports, running services, service versions, and basic information about an authorized target system.

## Introduction

Nmap is an open-source network scanning and security auditing tool. It is widely used during the scanning and enumeration phases of a Vulnerability Assessment and Penetration Testing (VAPT) process.

Nmap can help identify:

- Active hosts
- Open and closed ports
- Running network services
- Service versions
- Basic operating system information
- Potentially exposed services

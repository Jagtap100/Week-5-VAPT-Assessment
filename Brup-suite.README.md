# Burp Suite – Intercept Requests

## Objective

Burp Suite was used to intercept and analyze HTTP requests generated by the browser during the authorized VAPT practical.

## Step 1 – Open Burp Suite

1. Open Kali Linux.
2. Go to Applications → Web Application Analysis → Burp Suite.
3. Start Burp Suite.
4. Select Temporary Project.
5. Select Use Burp Defaults.
6. Click Start Burp.

## Step 2 – Verify Burp Proxy

Go to:

Proxy → Proxy settings

Verify:

`text
IP Address: 127.0.0.1
Port: 8080

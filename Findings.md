# VAPT Findings

## Introduction

The VAPT assessment was performed using Nmap, Nikto, and Burp Suite in an authorized training environment.

The findings should be based on the actual results obtained during the practical.

---

## Finding 1 – Network Service Exposure

Tool: Nmap

Description:

Nmap was used to identify accessible ports and running services on the authorized training target.

Observation:

The scan identified network services running on accessible ports.

Impact:

Unnecessary exposed services can increase the attack surface of a system.

Recommendation:

- Disable unnecessary services.
- Restrict access to required services.
- Apply appropriate firewall rules.
- Allow access only from trusted networks where appropriate.

Evidence:

Refer to the Nmap scan screenshots.

---

## Finding 2 – Web Server Security Observation

Tool: Nikto

Description:

Nikto was used to identify potential web-server configuration issues, information disclosure, exposed resources, and other security observations.

Impact:

Web-server configuration weaknesses or unnecessary information disclosure may provide useful information to an attacker.

Recommendation:

- Keep server software updated.
- Minimize server information disclosure.
- Remove unnecessary files and directories.
- Review web-server configuration.
- Implement appropriate security headers.

Evidence:

Refer to the Nikto scan screenshot.

---

## Finding 3 – HTTP Request Analysis

Tool: Burp Suite

Description:

Burp Suite was used to intercept and analyze HTTP requests generated by the browser.

Observation:

The HTTP request contained information such as the request method, path, host, headers, and other request details.

Impact:

Improper handling of sensitive information or session data may increase security risks.

Recommendation:

- Use HTTPS for secure communication.
- Implement secure session management.
- Configure secure cookies where applicable.
- Avoid transmitting sensitive information over unencrypted connections.

Evidence:

Refer to the Burp Suite intercepted request and HTTP History screenshots.

- Apply security patches.
